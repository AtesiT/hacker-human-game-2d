# Спрайты

Пока здесь пусто, игра рисует цветные заглушки с подписями.

Чтобы заменить заглушку, положите сюда PNG с именем ключа ассета из
[`src/data/assets.ts`](../../data/assets.ts) — например, `desk.png`.
Файл подхватится при следующем запуске, подпись заглушки пропадёт, код менять не нужно.

Размер листа: `frameW × cols` на `frameH × rows` пикселей, кадры идут слева направо и сверху вниз.
