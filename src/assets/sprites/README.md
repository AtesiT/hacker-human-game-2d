# Спрайты

Пока здесь пусто, игра рисует цветные заглушки с подписями.

Чтобы заменить заглушку, положите сюда PNG с именем ключа ассета из
[`src/data/assets.ts`](../../data/assets.ts) — например, `desk.png`.
Файл подхватится при следующем запуске, подпись заглушки пропадёт, код менять не нужно.

Размер листа: `frameW × cols` на `frameH × rows` пикселей, кадры идут слева направо и сверху вниз.

| Файл | Размер листа | Что в нём |
| --- | --- | --- |
| `tiles.png` | 32×16 | два тайла 16×16: пол, стена |
| `player.png` | 64×96 | 4 ряда (вниз, влево, вправо, вверх) × 4 кадра шага 16×24 |
| `desk.png` | 48×32 | стол |
| `bed.png` | 32×48 | кровать |
| `shelf.png` | 32×16 | шкаф |
| `couch.png` | 48×16 | диван |
| `fridge.png` | 16×16 | холодильник |
| `rug.png` | 64×48 | ковёр |
| `window.png` | 32×16 | окно |
| `door.png` | 32×16 | дверь |
| `rack.png` | 16×32 | серверная стойка |
| `farm.png` | 32×32 | майнинг-ферма |
