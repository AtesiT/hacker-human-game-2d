# Hacker Human Game 2D

Пиксельная игра с видом сверху: бывший айтишник, а теперь хакер, сидит в своей комнате
в маленьком американском городке. Он покупает серверные стойки и майнинг-фермы,
расставляет их по комнате, берёт заказы на взлом и копит деньги.

Сделано на TypeScript, Vite и Phaser 3. Графика пока условная: цветные прямоугольники
с подписями, которые потом можно заменить спрайтами, не трогая код.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 22.12 или новее. Подходит и ветка 20 — начиная с 20.19.

```bash
npm run dev
```

Команда сама установит зависимости при первом запуске и откроет игру во вкладке браузера
(обычно это `http://localhost:5173`). Отдельно выполнять `npm install` не нужно.

## Управление

Только клавиатура. Переключать раскладку не нужно: в русской всё работает так же.

| Клавиши | Что делают |
| --- | --- |
| `W` `A` `S` `D` или стрелки | Ходить. В терминале — выбирать строку и вкладку. При расстановке — двигать устройство. |
| `E` или `Enter` | Открыть терминал у стола, купить, взять заказ, поставить устройство. |
| `Esc` | Закрыть терминал, отменить расстановку. |

Если клавиши не действуют, кликните по игре: браузер передаёт нажатия только той странице,
на которой стоит фокус. Игра сама напомнит об этом надписью.

Картинка увеличивается только в целое число раз — так пиксели остаются ровными.
Если игра выглядит мелкой, разверните браузер на весь экран клавишей `F11`.

## Как играть

1. Подойдите к столу — он обведётся рамкой — и нажмите `E`. Откроется терминал.
2. На вкладке «Магазин» купите устройство и выберите для него место в комнате.
   Зелёный контур — поставить можно, красный — нельзя. Деньги списываются в момент установки,
   поэтому отмена по `Esc` ничего не стоит.
3. Каждое устройство раз в минуту приносит доход. Отсчёт у каждого свой — с момента установки.
4. На вкладке «Заказы» возьмите заказ на взлом. Он выполняется сам, пока вы ходите по комнате.
   Через 30 секунд станет известно, удался ли взлом.

| Устройство | Цена | Доход | Расход | Сколько можно | Место на полу |
| --- | --- | --- | --- | --- | --- |
| Серверная стойка | $500 | $5 в минуту | — | 4 | 1×2 клетки |
| Майнинг-ферма | $2000 | $15 в минуту | $2 в минуту | 2 | 2×2 клетки |

Заказ на взлом: 30 секунд, успех в 70% случаев, награда от $100 до $300.
За провал ничего не вычитается. Одновременно выполняется один заказ.

Убрать поставленное устройство нельзя. Поэтому игра не даёт загородить
устройствами проход к столу.

Доход идёт, только пока вкладка с игрой открыта и видна.

## Сохранение

Игра сама сохраняется в браузере: каждые 30 секунд, сразу после покупки
и при закрытии вкладки. Сохраняются деньги, устройства и место, где стоит игрок.
Заказ, который выполнялся в момент закрытия, не сохраняется.

Сохранение привязано к адресу, по которому открыта игра. У запуска через `npm run dev`,
у файла `dist/index.html` и у ссылки на GitHub Pages оно своё.

Чтобы начать заново, добавьте `?reset` к адресу страницы:
`http://localhost:5173/?reset`.

## Игра одним файлом

```bash
npm run build
```

Команда собирает `dist/index.html`. В этом файле вся игра: код, стили и шрифт.
Он открывается двойным кликом — без сервера и без Node.js. Файл можно переслать
или выложить на любой хостинг.

## Игра по ссылке

Репозиторий настроен на публикацию через GitHub Pages. После каждого обновления
ветки `main` игра сама собирается и выкладывается по адресу:

<https://atesit.github.io/hacker-human-game-2d/>

Чтобы ссылка заработала, один раз включите Pages: в репозитории откройте
**Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
Если публикация запустилась раньше, чем вы это сделали, она завершится ошибкой.
Тогда откройте вкладку **Actions**, выберите «Публикация на GitHub Pages»
и нажмите **Run workflow**.

## Как заменить заглушки спрайтами

Положите PNG в `src/assets/sprites/` и назовите его ключом ассета — например, `desk.png`.
Ключи и размеры перечислены в [`src/data/assets.ts`](src/data/assets.ts).
Игра найдёт файл сама: заглушка и её подпись исчезнут, код менять не нужно.

- Тайл — 16×16 пикселей, игрок — 16×24, палитра — DB32.
- Размер листа — `frameW × cols` на `frameH × rows` пикселей.
- Лист игрока `player.png` — 64×96: четыре ряда (вниз, влево, вправо, вверх)
  по четыре кадра шага. Первый кадр ряда — поза «стоит».
- Лист `tiles.png` — 32×16: тайл пола и тайл стены.

## Что где лежит

```
src/
  main.ts       запуск Phaser, масштаб канваса под окно
  data/         настройки и содержимое игры — менять баланс нужно здесь
    config.ts     размеры, скорость игрока, стартовые деньги, период автосохранения
    assets.ts     список ассетов и вид их заглушек
    room.ts       карта комнаты и мебель
    devices.ts    устройства из магазина: цена, доход, расход, лимит
    orders.ts     заказы на взлом: время, шанс, награда
    palette.ts    палитра DB32
  scenes/       сцены Phaser: загрузка, комната, слой интерфейса
  entities/     игрок, мебель, устройство
  systems/      управление, взаимодействие, экономика, расстановка, заказы, сохранение
  ui/           HUD, окно терминала и его вкладки
  assets/sprites/  сюда кладутся спрайты
```

Другие команды: `npm run typecheck` проверяет типы, `npm run preview` показывает собранную игру.
